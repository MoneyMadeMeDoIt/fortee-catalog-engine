<objective>
Patch the Tier 2 OpenAI billing-hard-limit blind spot in `scripts/fix-image-pollution.ts` (B-4 in `PRODUCTION-AUDIT-FINDINGS.md`). On 2026-05-14 the dry-run Tier 2 loop hit the OpenAI billing hard limit on every pid — each `generateGarmentView` call returned HTTP 400 with `code: 'billing_hard_limit_reached'`. The script logged the error per-pid but kept invoking the API 213 times in a row, wasting wall-clock + log space + (potential) extra HTTP quota.

Fix: detect the billing-hard-limit code ONCE, set a module-scope `__billingExhausted` flag, append a single sentinel trail row (`TIER2_BUDGET_EXHAUSTED`), and short-circuit the remaining pids to manual cascade. Operator sees one warning + clear trail rows + a clean summary that surfaces the cause.

Output:
- Patched `scripts/fix-image-pollution.ts` Tier 2 loop with the short-circuit logic.

- New tests in `tests/scripts/fix-image-pollution.test.ts` covering the short-circuit path.
- New test in `tests/lib/image-pollution-trail.test.ts` confirming `TIER2_BUDGET_EXHAUSTED` is NOT treated as terminal-op by `loadProcessedPids`.
