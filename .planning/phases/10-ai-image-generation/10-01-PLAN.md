    **Step 2: Create `src/lib/hue-utils.ts`** with these exports:
    - `rgbToHue(r: number, g: number, b: number): number` — standard RGB-to-HSL hue conversion. Returns degrees 0-360. Returns 0 for achromatic.
    - `hueDrift(hue1: number, hue2: number): number` — circular distance: `Math.min(Math.abs(h1-h2), 360-Math.abs(h1-h2))`
    - `isAchromatic(rgb: {r: number; g: number; b: number}): boolean` — returns true when `Math.max(r,g,b) - Math.min(r,g,b) < ACHROMATIC_THRESHOLD` (25). Import threshold from ai-image-types.
    - `async extractDominantHue(buffer: Buffer): Promise<{hue: number; achromatic: boolean; rgb: {r:number;g:number;b:number}}>` — uses `sharp(buffer).stats()` to get `.dominant`, then computes hue and achromatic flag.

    **Step 3: Create `src/lib/cost-tracker.ts`** — class `CostTracker`:
    - Constructor takes `budgetDollars: number` (default `DEFAULT_BUDGET` from types)
    - `canAfford(estimatedCost: number): boolean` — returns `this.cumulative + estimatedCost <= this.budget`
    - `record(cost: number): void` — adds to cumulative
    - `get total(): number` — returns cumulative
    - `get remaining(): number` — returns `budget - cumulative`
    - `estimateViewCost(): number` — returns `CANDIDATES_PER_CALL * COST_PER_IMAGE` ($0.126 per n=3 call)
    - Export `CostTracker` and re-export `COST_PER_IMAGE` from types.

    **Step 4: Create `tests/lib/` directory, then write test files.**
    - `tests/lib/hue-utils.test.ts`: Test all behaviors listed above. For `extractDominantHue`, mock `sharp` or use a tiny real PNG buffer (1x1 red pixel via `sharp({create:{width:1,height:1,channels:3,background:{r:255,g:0,b:0}}}).png().toBuffer()`).
    - `tests/lib/cost-tracker.test.ts`: Test canAfford, record, total, remaining, estimateViewCost. Test budget enforcement edge case (exact budget amount).
