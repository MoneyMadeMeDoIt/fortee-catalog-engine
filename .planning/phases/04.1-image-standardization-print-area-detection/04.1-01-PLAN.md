<objective>
Build the core image processing pipeline: detect garment boundaries via sharp.trim(), place garment at reference ratio on 2000x2000 canvas, and derive print area coordinates from placed garment bounds.

Purpose: Replace the simple fit:contain resize that produces inconsistent garment-to-canvas ratios, causing hardcoded print area coordinates to misalign on different garment shapes.
Output: Three new exported functions (detectGarmentBounds, placeGarmentOnCanvas, derivePrintAreaCoords), updated standardizeImage, new types, and comprehensive tests.
</objective>

/** Reference garment-to-canvas ratios measured from reference images (S05280 tops, L00550 hoodies). */
export const REFERENCE_RATIOS = {
  tops: { targetHeightFrac: 0.73, topOffsetFrac: 0.06 },
  hoodies: { targetHeightFrac: 0.78, topOffsetFrac: 0.05 },

/** Print area fractions relative to garment bounding box (not canvas). */
export const GARMENT_RELATIVE_PRINT_FRACTIONS = {
  tops: {
    'Front Print': { xFrac: 0.15, yFrac: 0.10, wFrac: 0.70, hFrac: 0.55 },
    'Back Print':  { xFrac: 0.13, yFrac: 0.10, wFrac: 0.74, hFrac: 0.53 },
  },

  },
} as const;

Implement `detectGarmentBounds(imageBuffer: Buffer): Promise<GarmentBounds>`:
- Get original dimensions via `sharp(imageBuffer).metadata()`
- Call `sharp(imageBuffer).trim({ background: '#ffffff', threshold: 10 }).toBuffer({ resolveWithObject: true })`
- Use `Math.abs()` on `trimOffsetLeft` and `trimOffsetTop`
- Safety check: if trimmed width < originalWidth * 0.3 OR trimmed height < originalHeight * 0.3, return full original dimensions as bounds (trim went wrong)
- Return `{ offsetLeft, offsetTop, width, height, originalWidth, originalHeight }`

Implement `placeGarmentOnCanvas(garmentBuffer: Buffer, targetHeightPx: number, targetTopOffsetPx: number, canvasSize = 2000): Promise<Buffer>`:
- Get garment aspect ratio from metadata
- Calculate scaled width = targetHeightPx * aspectRatio, leftOffset = (canvasSize - scaledWidth) / 2
- Resize garment to scaledWidth x targetHeightPx with fit: 'fill'
- Create white canvas and composite resized garment at (leftOffset, targetTopOffsetPx)
- Return PNG buffer

Implement `derivePrintAreaCoords(garmentLeftPx: number, garmentTopPx: number, garmentWidthPx: number, garmentHeightPx: number, categoryGroup: CategoryGroup, canvasSize = 2000): PrintAreaCoords`:
- Look up fractions from GARMENT_RELATIVE_PRINT_FRACTIONS[categoryGroup]
- For each print area, compute pixel x/y/w/h from garment bounds + fractions
- Convert to percentage of canvas: ((pixelValue / canvasSize) * 100).toFixed(2)
- Return Record with 'Front Print' and 'Back Print' keys

Update `standardizeImage` signature to:
```typescript
export async function standardizeImage(
  imageBuffer: Buffer,
  categoryGroup: CategoryGroup,
  canvasSize = 2000,
): Promise<{ buffer: Buffer; garmentPlacement: { left: number; top: number; width: number; height: number } }>
```
- Detect garment bounds
- Extract garment from source (use sharp extract or re-trim)
- Get reference ratio for categoryGroup
- Place on canvas at reference ratio
- Return buffer and garment placement (left, top, width, height on the final canvas)

The old `standardizeImage(imageBuffer: Buffer): Promise<Buffer>` signature changes. Existing callers (processProductImages) will be updated in Plan 02.
