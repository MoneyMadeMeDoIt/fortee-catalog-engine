## Decisions Made
- `categoryGroup` defaults to `'tops'` in `standardizeImage` and `processProductImages` so existing callers don't break while Plan 02 wires in the real category group
- `placeGarmentOnCanvas` uses `fit: 'fill'` because the caller already computed the correct target dimensions from the garment aspect ratio — no second resizing needed
- Safety threshold of 70% (trim removes >70% → fallback) chosen to catch pathological cases (dark garments on white, nearly-all-white images) without triggering on normal use
