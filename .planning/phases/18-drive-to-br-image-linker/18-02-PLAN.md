<objective>
Build `scripts/link-br-images.ts` — the deterministic Drive→BR image linker entry point.
It enumerates every supplier/pid Drive folder, parses canonical filenames via the
18-01 parser, joins to BR rows by (productId, normalizeColor), and overwrites the 7 image
columns (3 existing + 4 new) with canonical Drive URLs. Default mode is `--dry-run` (emits
an old→new diff TSV + miss TSV, writes nothing); `--apply` writes a backup TSV first, adds
absent columns by re-reading the live header, then writes via the chunked RAW writer.
The whole pipeline is never-blank-safe (D-08) and idempotent (D-11/OPS-02).

Purpose: Populate the catalog's 7 image columns from the standardized Drive library with
zero risk of wrong-color assignment, brand leak, blank-overwrite of good links, or header
drift — the five failure modes the research flagged as catastrophic at 24k rows.
Output: `scripts/link-br-images.ts` + unit tests; on a real --dry-run, `tmp/` diff/miss/backup TSVs.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Drive index → BR cell write | Canonical URLs cross into the shared 24k-row customer-facing sheet; a wrong/blank write is customer-visible |
| Local CLI flag → destructive apply | `--apply` mutates the live sheet; default-safe (dry-run) gates it |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-03 | Tampering | overwrite of a good link when Drive file absent | mitigate | D-08 never-blank: no update emitted, miss logged; unit-tested in Task 1 |
| T-18-04 | Tampering | header drift on the shared sheet (data lands one column off) | mitigate | D-06 re-read live header after appendDimension; by-name index; idempotent header add (P4) |
| T-18-05 | Tampering | off-by-one row write clobbers header row | mitigate | sheetRow = ri+2 with `>= 2` assertion (P5); diff TSV prints ranges for review |
| T-18-06 | Denial of service | unbounded Drive files.list hang | mitigate | local timeout(30s)+retry wrapper mirroring drive.ts isTimeoutError; pagination loop bounded |
| T-18-07 | Repudiation | no record of what changed before apply | mitigate | backup TSV written before any --apply write (D-10); diff + miss TSVs always emitted |
| T-18-SC | Tampering | npm/pip/cargo installs | accept | No new packages — only existing googleapis/vitest/tsx; no install task |
</threat_model>
