<objective>
Build the deterministic, pure parsing + join core for the Drive→BR image linker:
a pid-anchored / role-anchored canonical-filename parser, a color normalizer, and the
Drive-role → BR-column mapping table. This is the brand-leak-critical heart of Phase 18
(D-07) and is isolated into a standalone module so it can be unit-tested against the
known Q-Tees/H08050 regression case BEFORE any Drive or Sheets I/O exists.

Purpose: The 2026-05-29 finalize brand-leak bug (hyphenated brands like Q-Tees leaking
into color names) must never recur. Splitting filenames on every `-`/`_` is the
known-broken behavior. By extracting the parser into a pure module with a test suite, the
correctness of color extraction is proven independently of network calls.
Output: `scripts/lib/br-image-parser.ts` with `parseCanonicalFilename`, `normalizeColor`,
`ROLE_TO_COLUMN`, `CANONICAL_ROLES`; a passing regression suite.
</objective>
