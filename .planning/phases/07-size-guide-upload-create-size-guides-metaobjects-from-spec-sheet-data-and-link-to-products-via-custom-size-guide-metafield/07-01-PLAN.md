1. **src/shopify/mutations.ts** -- Add `UPSERT_SIZE_GUIDE` mutation string. Identical shape to `UPSERT_PRINT_AREA` (copy it, rename the export). The metaobjectUpsert mutation is generic -- same GraphQL works for any type.

2. **src/sheets/spec-sheet.ts** -- Add `readSpecSheetStructured()` function below the existing `readSpecSheet()`. Same read logic (spreadsheets.values.get, same header parsing) but:
   - Also find `sizeOrder` column index (optional -- may not exist in all sheets)
   - Attach sizeOrder to each SizeSpec during collection (extend the SpecSheetRow interface to include optional `sizeOrder?: number`)
   - Return `specsByProduct` Map directly (Map<string, SizeSpec[]>) instead of formatting
   - Sort specs within each product group: first by sizeOrder (if present), then fallback to standard size order constant `['XS','S','M','L','XL','2XL','3XL','4XL','5XL','6XL']`
   - Export the new function. Do NOT modify existing `readSpecSheet()`.

3. **src/shopify/metaobjects.ts** -- Add three exports:

   a. `SizeGuideFields` interface:
   ```typescript
   export interface SizeGuideFields {
     sizes: string[];
     variables: Array<{ label: string; values: number[] }>;
     title: string;
   }
   ```

   b. `buildSizeGuideMetaobjectFields(guide: SizeGuideFields)` pure function returning `{key, value}[]`:
   - `title` field: guide.title
   - `description` field: empty rich text JSON (type:root with empty paragraph -- see research Pattern 4)
   - `sizes` field: JSON.stringify(guide.sizes)
   - For each variable (max 5, warn if >5): `variable_N_label` = label string, `variable_N_values` = JSON.stringify(values.map(v => ({value: v, unit: 'in'})))
   - Do NOT include `how_to_measure` field (leave for manual admin setup)

   c. `transformSpecsToSizeGuide(productId: string, productName: string, specs: SizeSpec[])` pure function:
   - Groups specs by sizeName to get unique sizes list
   - Groups specs by specName to get unique variables
   - For each variable, collects values in size order (parallel to sizes array)
   - Parses value strings to floats via parseFloat()
   - Returns SizeGuideFields object with title `"${productName} Size Guide"`

   d. `upsertSizeGuideMetaobject(client, productId, productName, specs: SizeSpec[])` async function:
   - Calls transformSpecsToSizeGuide to build fields
   - Handle: `size-guide-${productId.toLowerCase().replace(/[^a-z0-9-]/g, '-')}`
   - Calls client.request(UPSERT_SIZE_GUIDE, ...) with handle type 'size_guides'
   - Checks userErrors, throws on error
   - Returns metaobject GID string

   e. `linkSizeGuideToProduct(client, productGid, sizeGuideGid)` async function:
   - Uses METAFIELDS_SET mutation (already imported)
   - Metafield: namespace 'custom', key 'size_guide', type 'metaobject_reference' (SINGLE, not list)
   - Value is the raw GID string (NOT JSON.stringify([gid]))
   - Checks userErrors, throws on error
