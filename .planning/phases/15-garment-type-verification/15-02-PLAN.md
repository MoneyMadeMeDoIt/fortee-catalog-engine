<objective>
Wire the verifier helper (built in Plan 01) into `generateGarmentView()` so AI-generated back/side candidates that fail garment-type comparison are excluded from winner selection, the retry round fires under the strict AND predicate, and total type-match failure produces a `null` return + rejects-TSV log. Update the two in-tree callers in `audit-runner.ts` to thread `pid` through.

Purpose: This is the surgical change that closes the A343 regression bug class. The retry/skip/log scaffolding is built; this plan moves the filter predicate from `c.passesHue` to `c.passesHue && c.passesType` at two sites, extends `CandidateResult` with two fields, replaces the D-04 hue-fallback block to handle type-failure by skipping (not falling-back), and proves the wiring with 6 mocked-OpenAI tests.

Output:
- `src/lib/ai-image-generator.ts` with type-match filter wired into `scoreCandidates()` + `generateGarmentView()`
- `src/lib/audit-runner.ts` callers updated to pass `pid`
- 6 new mocked-OpenAI tests in `tests/lib/ai-image-generator.test.ts` (test file extended, not replaced)
- A343 regression class is now caught at generation time
</objective>
