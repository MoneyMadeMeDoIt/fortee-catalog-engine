  <files>src/shopify/metaobjects.ts, tests/shopify/metaobjects.test.ts</files>
  <behavior>
    - buildPrintAreaHandle('T-Shirt', 'Print', 'Left Chest') returns 't-shirt-print-left-chest'
    - buildPrintAreaHandle('Cap', 'Embroidery', 'Front Center') returns 'cap-embroidery-front-center'
    - buildPrintAreaHandle handles special chars (spaces, slashes) by converting to hyphens
    - buildPrintAreaInput creates correct metaobject fields array from DecorationPlacement
    - buildPrintAreaMetafieldInput creates JSON-stringified array of GIDs: '["gid://shopify/Metaobject/123"]'
    - buildPrintAreaMetafieldInput with empty array returns '[]'
  </behavior>
  <action>
    Create src/shopify/metaobjects.ts with:

    1. buildPrintAreaHandle(category: string, method: string, placement: string): string
       - Concatenate category-method-placement, lowercase, replace non-alphanumeric with hyphens, deduplicate, trim
       - Deterministic for idempotent metaobjectUpsert

    2. buildPrintAreaInput(placement: DecorationPlacement): MetaobjectUpsertInput
       - Maps DecorationPlacement fields to metaobject fields array:
         { key: "method", value: placement.method }
         { key: "placement", value: placement.placementName }
         { key: "max_size", value: placement.maxSize }
         { key: "common_sizes", value: placement.commonSizes }
         { key: "notes", value: placement.notes }

    3. buildPrintAreaMetafieldInput(productGid: string, metaobjectGids: string[]): MetafieldSetInput
       - Returns { ownerId: productGid, namespace: "custom", key: "print_areas", type: "list.metaobject_reference", value: JSON.stringify(metaobjectGids) }
       - CRITICAL: value must be JSON.stringify of the GID array (Pitfall 6 from research)

    4. async upsertPrintAreas(client: any, category: string, placements: DecorationPlacement[]): Promise<string[]>
       - For each placement: build handle, build input, call UPSERT_PRINT_AREA mutation
       - Returns array of metaobject GIDs
       - Logs errors but continues (partial success is acceptable)

    5. async linkPrintAreasToProduct(client: any, productGid: string, metaobjectGids: string[]): Promise<void>
       - Calls METAFIELDS_SET with buildPrintAreaMetafieldInput result
       - Throws on userErrors

    Create tests/shopify/metaobjects.test.ts testing pure functions (buildPrintAreaHandle, buildPrintAreaInput, buildPrintAreaMetafieldInput). Mock the client for upsertPrintAreas and linkPrintAreasToProduct.
  </action>

  </verify>
  <done>buildPrintAreaHandle produces deterministic handles. buildPrintAreaInput maps all DecorationPlacement fields. buildPrintAreaMetafieldInput JSON-stringifies GID arrays correctly. All tests green.</done>
