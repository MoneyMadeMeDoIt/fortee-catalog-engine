<task type="auto" tdd="true">
  <name>Task 1: Product push orchestrator</name>
  <files>src/shopify/product-push.ts, src/shopify/index.ts, tests/shopify/product-push.test.ts</files>
  <behavior>
    - buildProductSetInput groups rows by styleID and builds correct ProductSetInput
    - ProductSetInput includes title, handle, descriptionHtml, vendor, productType, status:ACTIVE, templateSuffix, tags, productOptions (Color + Size), variants
    - productOptions extracts unique colors and sizes from row group
    - Tags include brandName, baseCategory, gender
    - Files are collected from ALL rows in the group (unique URLs across FrontImage, BackImage, DirectSideImage), not just the first row
    - isUpdate=true omits files field (Pitfall 2 from research)
    - buildFiles with 3 rows having different color-specific images collects all unique URLs
    - buildFiles deduplicates identical URLs across rows
  </behavior>
  <action>
    Create src/shopify/product-push.ts with:

    1. buildProductSetInput(rows: SheetRow[], isUpdate: boolean): { input: ProductSetInput, identifier: { handle: string } }
       - Groups rows (all rows share same styleID -- caller filters)
       - Uses first row for product-level fields: productName -> title, description -> descriptionHtml, brandName -> vendor, baseCategory -> productType
       - handle = buildHandle(row.productName, row.styleID)
       - status = "ACTIVE"
       - templateSuffix = getTemplateSuffix(row.baseCategory)
       - tags = [row.brandName, row.baseCategory, row.gender].filter(Boolean)
       - productOptions: extract unique colorName values for Color option, unique sizeName values for Size option
       - variants = buildVariants(rows)
       - files = isUpdate ? undefined : buildFiles(rows) -- pass ALL rows, not just rows[0]. buildFiles collects unique image URLs across all rows so color-specific images from different rows are captured.
       - identifier = { handle }

    **SHOP-05 approach note:** SHOP-05 specifies "staged uploads" but research (04-RESEARCH.md) confirms external URL pass-through via the productSet `files` field is the simpler and preferred approach since supplier images are already publicly accessible CDN URLs. Shopify fetches them directly. If Shopify's fetcher cannot reach the CDN (returns fetch errors), fall back to staged uploads: download images locally via node:stream, then use stagedUploadsCreate to upload. This fallback is NOT implemented in this phase -- it would be added as a gap closure task if external URL fetching fails during human verification (Task 3).

    2. async pushProduct(styleID: string): Promise<{ productGid: string; variantCount: number; metaobjectCount: number }>
       - Create Shopify client via createShopifyClient()
       - Read all sheet rows, filter to matching styleID
       - If no rows found, throw error
       - Build productSet input (isUpdate = false for now; SHOP-07 handled by productSet identifier upsert)
       - Call PRODUCT_SET mutation
       - Check userErrors, throw if any
       - Extract product GID from response
       - Resolve garment category via resolveCategory(rows[0].baseCategory)
       - If category found: get decoration placements, upsertPrintAreas, linkPrintAreasToProduct
       - Return { productGid, variantCount, metaobjectCount }
       - Log each step via winston (creating product, uploading images, creating metaobjects, linking)

    3. Create src/shopify/index.ts barrel export:
       - Re-export pushProduct from product-push
       - Re-export createShopifyClient from client
       - Re-export setupPrintAreaDefinitions from metaobject-setup

    Create tests/shopify/product-push.test.ts testing buildProductSetInput (pure function):
    - Correct title, handle, vendor, productType from first row
    - Unique colors and sizes in productOptions
    - Variants match row count
    - Files included when isUpdate=false, omitted when isUpdate=true
    - Tags include brand, category, gender
    - Files collected from ALL rows (3 rows with different FrontImage URLs = 3 front images in files array)
    - Duplicate URLs across rows are deduplicated
  </action>
  <verify>
    <automated>npx vitest run tests/shopify/product-push.test.ts</automated>
  </verify>
  <done>buildProductSetInput correctly builds full ProductSetInput from SheetRow[]. Images collected across all rows with deduplication. pushProduct orchestrates client -> productSet -> metaobjects -> metafields. Barrel export works. Tests green.</done>
</task>
