       - ProductSetInput: title, handle, descriptionHtml, vendor, productType, status, templateSuffix, tags, productOptions, variants, files
       - ProductVariantSetInput: optionValues (array of {optionName, name}), price, sku, barcode
       - ProductOptionInput: name, position, values (array of {name})
       - FileSetInput: originalSource, alt, contentType
       - MetaobjectField: key, value
       - MetaobjectUpsertInput: fields (MetaobjectField[])
       - MetaobjectHandleInput: type, handle
       - MetafieldSetInput: ownerId, namespace, key, type, value

    3. Create src/shopify/client.ts:
       - Export createShopifyClient() that reads SHOPIFY_STORE_DOMAIN and SHOPIFY_ADMIN_ACCESS_TOKEN from env
       - Uses createAdminApiClient from @shopify/admin-api-client with apiVersion '2025-01'
       - Throws descriptive error if env vars missing

    4. Create src/shopify/mutations.ts with exported GraphQL mutation strings:
       - PRODUCT_SET: productSet mutation with synchronous:true, accepts $input and $identifier, returns product.id, product.handle, variants edges, userErrors
       - METAFIELDS_SET: metafieldsSet mutation, returns metafields and userErrors
       - CREATE_PRINT_AREA_DEFINITION: metaobjectDefinitionCreate for "print_area" type with fields: method, placement, max_size, common_sizes, notes
       - UPSERT_PRINT_AREA: metaobjectUpsert accepting $handle and $metaobject, returns metaobject.id, metaobject.handle, userErrors
       - CREATE_METAFIELD_DEFINITION: metafieldDefinitionCreate for the product print_areas list.metaobject_reference field

    5. Create src/shopify/template-map.ts:
       - TEMPLATE_SUFFIX_MAP record mapping all 7 GarmentCategory values to lowercase-hyphenated suffixes
       - Export getTemplateSuffix(baseCategory: string): string | undefined

    6. Create tests/shopify/template-map.test.ts testing all category mappings and unknown input.

    - buildVariants with 3 rows produces 3 variant objects with correct optionValues, price, sku, barcode
    - buildVariants maps sellPrice to price, partNumber to sku, PartID to barcode
    - buildVariants handles empty sellPrice gracefully (defaults to 0)
    - buildFiles with all 3 images returns 3 FileSetInput objects with correct alt text
    - buildFiles with only FrontImage returns 1 FileSetInput
    - buildFiles with no images returns empty array
  </behavior>
  <action>
    Create src/shopify/variants.ts with three exported functions:

    1. buildHandle(productName: string, styleID: string): string
       - Concatenates productName + styleID
       - Lowercases, replaces non-alphanumeric with hyphens, deduplicates hyphens, trims leading/trailing hyphens
       - Must be deterministic for idempotent upsert (SHOP-07)

    2. buildVariants(rows: SheetRow[]): ProductVariantSetInput[]
       - Each row becomes one variant with optionValues [{optionName:"Color", name:row.colorName}, {optionName:"Size", name:row.sizeName}]
       - price: parseFloat(row.sellPrice) || 0
       - sku: row.partNumber
       - barcode: row.PartID

    3. buildFiles(row: SheetRow): FileSetInput[]
       - Checks FrontImage, BackImage, DirectSideImage
       - Only includes non-empty URLs
       - alt text format: "{productName} - Front/Back/Side"
       - contentType: "IMAGE"

    Create tests/shopify/variants.test.ts testing buildVariants and buildFiles with mock SheetRow data.
    Create tests/shopify/handles.test.ts testing buildHandle determinism, special characters, edge cases.
