    - buildUpdates produces EnrichmentUpdate for each empty cell that has matching supplier data
    - buildUpdates uses correct cell references (Sheet1!{col}{row}) with 1-based row indexing (data row 0 = sheet row 2)
    - formatSizeChart converts SizeSpec[] to structured text like "S: Chest 36, Length 28 | M: Chest 38, Length 29"
    - mapSupplierToSheetFields maps a SupplierProduct to a flat Record of sheet column name -> value
    - Image fields only populate if the sheet cell is empty (never overwrite existing images)
    - writeUpdates calls batchUpdate with RAW valueInputOption
    - writeUpdates returns 0 and skips API call if updates array is empty
  </behavior>
  <action>
Create `src/sheets/merge.ts`:
- `formatSizeChart(specs: SizeSpec[]): string` -- Converts SizeSpec[] to structured text. Group by sizeName, join measurements with comma, join sizes with " | ". Example: "S: Chest 36, Length 28 | M: Chest 38, Length 29".
- `mapSupplierToSheetFields(product: SupplierProduct): Record<string, string>` -- Maps SupplierProduct fields to a flat object keyed by sheet column names using FIELD_MAPPING. For images: FrontImage = images[0]?.url, BackImage = images[1]?.url, DirectSideImage = images[2]?.url (only if image exists). For sizeChart: format sizeChartData using formatSizeChart if present. For description, careInstructions: direct mapping.
- `buildUpdates(row: SheetRow, supplierData: Record<string, string>, headers: string[], rowIndex: number, sheetName: string): EnrichmentUpdate[]` -- For each field in supplierData, check if the corresponding SheetRow field is empty (falsy or whitespace-only). If empty and supplier has a value, create an EnrichmentUpdate with range = `{sheetName}!{columnLetter}{rowIndex + 2}` (row index 0 = sheet row 2, since row 1 = headers). Uses columnToLetter with the header index lookup.

Create `src/sheets/writer.ts`:
- `writeUpdates(sheets: sheets_v4.Sheets, spreadsheetId: string, updates: EnrichmentUpdate[]): Promise<number>` -- If updates is empty, return 0 without calling API. Otherwise call `spreadsheets.values.batchUpdate` with `valueInputOption: 'RAW'` and the updates array as `data`. Return `totalUpdatedCells` from response.

<task type="auto">
  <name>Task 2: Enrichment orchestrator and CLI script</name>
  <files>src/sheets/enrich.ts, scripts/enrich.ts</files>
  <action>
Create `src/sheets/enrich.ts`:
- `enrichSheet(options?: { supplier?: 'canada-sportswear' | 'ss-canada'; dryRun?: boolean }): Promise<EnrichmentReport>`
- Orchestration flow:
  1. Create sheets client via `createSheetsClient()`
  2. Read spreadsheet ID from `process.env.GOOGLE_SPREADSHEET_ID` (throw if missing)
  3. Read all rows via `readAllRows(sheets, spreadsheetId, sheetName)`
  4. Determine which suppliers to extract: if `options.supplier` specified, extract only that one; otherwise extract both via `extractFromSupplier` for each unique `supplierCode` found in the sheet rows
  5. Build a lookup Map: `Map<string, SupplierProduct[]>` keyed by styleNumber for quick matching
  6. For each sheet row:
     a. Look up supplierCode via SUPPLIER_CODE_MAP to get adapter name
     b. Find matching SupplierProduct by styleID
     c. If no match, increment `skippedNoMatch` counter, continue
     d. Call `mapSupplierToSheetFields(product)` to get flat supplier data
     e. Call `buildUpdates(row, supplierData, headers, rowIndex, sheetName)` to get cell updates
     f. Collect all updates
  7. If `dryRun`, log what would be written but skip the API call
  8. Otherwise call `writeUpdates(sheets, spreadsheetId, allUpdates)`
  9. Return EnrichmentReport with counts
- Use winston logger for progress: "Reading sheet...", "Extracting from {supplier}...", "Processing {n} rows...", "Enriched {n} rows, wrote {n} cells, skipped {n} (no match)"

Create `scripts/enrich.ts`:
- CLI entry point, similar pattern to existing `scripts/scrape.ts`
- Parse args: `--supplier <name>` (optional, filter to one supplier), `--dry-run` (show changes without writing)
- `--help` flag with usage docs
- Call `enrichSheet()` with parsed options
- Print summary: rows scanned, rows enriched, cells written, skipped, errors
- Exit code 1 if any errors, 0 otherwise
- Run command: `npx tsx scripts/enrich.ts`
