    Create `scripts/calibrate-scorer.ts` per D-04 and Research Pattern 6.

    **Purpose:** Fetch product images from existing Shopify products, run each through `scoreImageQuality()`, and output a tab-separated report to stdout.

    **Implementation:**
    1. Import `scoreImageQuality` from `../src/shopify/image-scorer.js` and `downloadImage` from `../src/shopify/image-standardizer.js`
    2. Import the Shopify client from `../src/shopify/client.js` (read client.ts first to see the exact export pattern and GraphQL request method)
    3. Write a GraphQL query to fetch the first 20 products with their media images:
       ```graphql
       query ($cursor: String) {
         products(first: 20, after: $cursor) {
           edges {
             node {
               id
               title
               media(first: 5) {
                 edges {
                   node {
                     ... on MediaImage {
                       image {
                         url
                         altText
                       }
                     }
                   }
                 }
               }
             }
           }
           pageInfo { hasNextPage endCursor }
         }
       }
       ```
    4. Paginate to collect at least 50 image URLs (up to 3 pages of 20 products)
    5. For each image URL:
       a. Download with `downloadImage(url)`
       b. Score with `scoreImageQuality(buffer)`
       c. Output a line: `product_title\timage_alt\tscore\tverdict\treasons\tblur\tresolution\tproportion\tcontent`
    6. Print a summary footer: total images, pass count, fail count, fail rate percentage
    7. Handle download/score errors gracefully — print error line and continue to next image
    8. Usage: `npx tsx scripts/calibrate-scorer.ts > calibration-report.tsv`

    **Output format (header + data lines):**
    ```
    product	alt	score	verdict	reasons	blur	resolution	proportion	content
    CSW S05280	Front Print	82	pass		95	100	100	100
    CSW L00550	Front Print	45	fail	Image is too blurry (sharpness: 6.2, min: 10.0)	62	100	100	100
    ```

    **Summary footer (to stderr so it doesn't pollute TSV):**
    ```
    === Calibration Summary ===
    Total images: 58
    Pass: 52 (89.7%)
    Fail: 6 (10.3%)
    ```
