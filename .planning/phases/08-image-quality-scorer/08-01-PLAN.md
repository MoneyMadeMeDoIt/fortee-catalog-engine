    ```typescript
    import sharp from 'sharp';
    import { detectGarmentBounds, REFERENCE_RATIOS } from './image-standardizer.js';
    import { logger } from '../lib/logger.js';
    import type { ImageQualityResult, GarmentBounds, CategoryGroup } from './types.js';
    ```

    **Internal types:**
    ```typescript
    interface DimensionResult {
      score: number;   // 0-100
      reasons: string[];
    }
    ```

    **Exported threshold constants** (placeholder values — calibrated in Plan 02):
    ```typescript
    export const QUALITY_THRESHOLDS = {
      BLUR_MIN_STDEV: 10.0,
      MIN_GARMENT_PX: 400,
      PROPORTION_TOLERANCE: 0.20,
      PRINT_CENTER_STDEV: 15.0,
      SKIN_RATIO: 0.05,
      BG_WHITE_MIN: 230,
      WATERMARK_FULL_STDEV: 20.0,
    } as const;
    ```

    **Main function:** `scoreImageQuality(buffer: Buffer, categoryGroup?: CategoryGroup): Promise<ImageQualityResult>`
    1. Call `detectGarmentBounds(buffer)` once
    2. Extract garment region using `sharp(buffer).extract({ left: bounds.offsetLeft, top: bounds.offsetTop, width: bounds.width, height: bounds.height }).png().toBuffer()`
    3. Run all 4 checks in parallel via `Promise.all([checkBlur(garmentBuffer), checkResolution(bounds), checkProportion(bounds), checkContentSuitability(buffer, garmentBuffer, bounds)])`
    4. Collect all reasons from sub-checks
    5. Compute weighted composite score: blur 30%, resolution 20%, proportion 20%, content 30%
    6. Verdict: `'fail'` if any reasons exist, `'pass'` otherwise
    7. Return `{ score, verdict, reasons, dimensions: { blur, resolution, proportion, content } }`

    **checkBlur(garmentBuffer: Buffer): Promise<DimensionResult>** (per D-02, Research Pattern 2):
    - Apply Laplacian kernel `[-1,-1,-1,-1,8,-1,-1,-1,-1]` via `sharp(garmentBuffer).greyscale().convolve({ width: 3, height: 3, kernel: [-1,-1,-1,-1,8,-1,-1,-1,-1] }).stats()`
    - Read `stats.channels[0].stdev` as blur metric (higher = sharper)
    - Score: `Math.min(100, Math.round((stdev / QUALITY_THRESHOLDS.BLUR_MIN_STDEV) * 100))`
    - Fail reason if stdev < BLUR_MIN_STDEV: `Image is too blurry (sharpness: ${stdev.toFixed(1)}, min: ${BLUR_MIN_STDEV})`

    **checkResolution(bounds: GarmentBounds): DimensionResult** (per Research Pattern 3):
    - Synchronous — uses bounds directly, no sharp call
    - `shortSide = Math.min(bounds.width, bounds.height)`
    - Score: `Math.min(100, Math.round((shortSide / QUALITY_THRESHOLDS.MIN_GARMENT_PX) * 100))`
    - Fail if shortSide < MIN_GARMENT_PX: `Garment resolution too low: ${bounds.width}x${bounds.height}px (min: ${MIN_GARMENT_PX}px short side)`

    **checkProportion(bounds: GarmentBounds): DimensionResult** (per D-05, Research Pattern 4):
    - Detect fallback bounds: if `bounds.offsetLeft === 0 && bounds.offsetTop === 0 && bounds.width === bounds.originalWidth && bounds.height === bounds.originalHeight`, return `{ score: 50, reasons: ['Garment bounds detection failed — proportion unknown'] }`
    - `heightFrac = bounds.height / bounds.originalHeight`
    - Use unified range: `minFrac = Math.min(REFERENCE_RATIOS.tops.targetHeightFrac, REFERENCE_RATIOS.hoodies.targetHeightFrac) - QUALITY_THRESHOLDS.PROPORTION_TOLERANCE` and `maxFrac = Math.max(...) + PROPORTION_TOLERANCE`
    - Score: 100 if in range, 0 if out
    - Fail reason if out of range: `Garment proportion out of range: ${(heightFrac*100).toFixed(0)}% height (expected ${(minFrac*100).toFixed(0)}–${(maxFrac*100).toFixed(0)}%)`

    **checkContentSuitability(originalBuffer: Buffer, garmentBuffer: Buffer, bounds: GarmentBounds): Promise<DimensionResult>** (per D-03, Research Patterns 5a-5d):
    Contains 4 sub-checks. Accumulate reasons. Score = 100 if no reasons, 0 if any.

    **5a. Print detection** — Extract center 50% of garment: `sharp(garmentBuffer).extract({ left: Math.floor(w*0.25), top: Math.floor(h*0.25), width: Math.min(Math.floor(w*0.5), w - Math.floor(w*0.25)), height: Math.min(Math.floor(h*0.5), h - Math.floor(h*0.25)) })`. Apply greyscale + Laplacian convolve + stats. If `stdev > PRINT_CENTER_STDEV`, add reason: `Garment appears to have existing print/logo (content score: ${stdev.toFixed(1)})`

    **5b. On-model detection** — Downsample original buffer to 100x100 with `sharp(originalBuffer).resize(100, 100, { fit: 'cover' }).raw().toBuffer()`. Count pixels where `R>95 && G>40 && B>20 && R>G && R>B && (R-G)>15`. If ratio > SKIN_RATIO, add reason: `Image appears to show an on-model photo (skin-tone ratio: ${(ratio*100).toFixed(1)}%)`

    **5c. Background whiteness** — If `bounds.offsetTop >= 10`, extract top strip: `sharp(originalBuffer).extract({ left: 0, top: 0, width: bounds.originalWidth, height: bounds.offsetTop }).stats()`. Compute mean brightness of RGB channels. If mean < BG_WHITE_MIN, add reason: `Background is not white (mean brightness: ${mean.toFixed(0)}, min: ${BG_WHITE_MIN})`

    **5d. Watermark detection** — Apply greyscale + Laplacian on full garment buffer (same as blur but read stdev differently). If `fullStdev > WATERMARK_FULL_STDEV` AND the center stdev from 5a was low (< PRINT_CENTER_STDEV), add reason: `Image appears to have watermark overlay (edge score: ${fullStdev.toFixed(1)})`. Note: fullStdev is already computed in checkBlur — but since checks run in parallel, recompute here or restructure to share. Simplest: recompute in 5d since it's fast.

    **CRITICAL anti-patterns to avoid:**
    - Do NOT analyze blur on full canvas — always use extracted garment buffer
    - Do NOT use `stats().sharpness` — it's non-monotonic. Use `convolve()` + `stdev`
    - Do NOT check DPI from `metadata().density` — undefined for most supplier PNGs
    - Clamp all `extract()` regions to avoid out-of-bounds: `Math.min(left + width, imageWidth)`
    - Call `detectGarmentBounds()` only ONCE per image
