    Create `src/lib/image-sourcer.ts` with the following structure. Per D-01 through D-06:

    **Exported types:**
    ```typescript
    export type ImageView = 'front' | 'back' | 'side';

    export interface SourcedView {
      url: string;
      score: number;
      verdict: 'pass' | 'fail';
    }

    export interface SourcedImages {
      front: SourcedView | null;
      back: SourcedView | null;

    }
    ```

    **Internal helper — scoreUrl:**
    ```typescript
    async function scoreUrl(url: string): Promise<SourcedView>
    ```
    Calls `downloadImage(url)` from `../shopify/image-standardizer.js`, then `scoreImageQuality(buffer)` from `../shopify/image-scorer.js`. Returns `{ url, score: result.score, verdict: result.verdict }`.

    **Internal helper — pickBest:**
    ```typescript
    export function pickBest(views: SourcedView[]): SourcedView | null
    ```
    Returns highest-scoring candidate. Returns null if array empty. Per D-03, does NOT filter by verdict — returns best even if all fail.

    **OMG OneSource classType view mapping (per RESEARCH.md Pattern 3):**
    ```typescript
    const VIEW_CLASS_TYPES: Record<number, ImageView> = {
      1007: 'front',  // Front
      1006: 'front',  // Primary (fallback front)
      1001: 'front',  // Blank garment (fallback front)
      1008: 'back',   // Rear
      1009: 'side',   // Right side
      1010: 'side',   // Left side
    };
    ```

    **fetchOMGImages(styleId: string, colorName?: string): Promise<Partial<Record<ImageView, SourcedView>>>**
    - Creates OneSource client using env vars: `ONESOURCE_KEY_ID`, `ONESOURCE_KEY_PASSWORD`, `CSW_SUPPLIER_CODE` (CSW is the OneSource supplier that carries these styles — per existing canada-sportswear.ts pattern).
    - Calls `client.getMediaContent(styleId)` then `parseMediaContentFromXml($)`.
    - For each media item: look up classTypes[].id in VIEW_CLASS_TYPES. If match found and media item has a URL, call `scoreUrl(url)`.
    - When `colorName` provided, prefer media items where `color` field matches (case-insensitive). When not provided, accept first valid match per view.
    - Return map of view -> SourcedView. Only include first match per view (don't overwrite higher-priority classTypeIds).
    - Priority order: 1007 > 1006 > 1001 for front.
    - Wrap in try/catch — on error, log warning via `logger.warn()` and return `{}`.

    **fetchCSWImages(styleId: string): Promise<Partial<Record<ImageView, SourcedView>>>**
    - CSW is confirmed front-only (per RESEARCH.md Pitfall 3).
    - Use search URL: `https://canadasportswear.com/search?type=product&q=${encodeURIComponent(styleId)}`.
    - Fetch HTML, parse with `cheerio.load(html)`. Extract first product link from search results.
    - If product found, fetch `{productUrl}.json` to get Shopify product JSON. Extract first image `src` from `product.images[0].src`.
    - Score the image URL and return `{ front: scoredView }`.
    - On any error, log warning and return `{}`.

    **fetchSSCanadaImages(styleId: string): Promise<Partial<Record<ImageView, SourcedView>>>**
    - Check `process.env.SS_ACCOUNT_NUMBER` and `process.env.SS_API_KEY`. If either missing, log `logger.warn('S&S Canada REST credentials not set (SS_ACCOUNT_NUMBER, SS_API_KEY) — skipping')` and return `{}`.
    - Call `https://api.ssactivewear.com/v2/products/?styleid=${encodeURIComponent(styleId)}&fields=colorFrontImage,colorBackImage,colorSideImage`.
    - Auth: `Authorization: Basic ${Buffer.from(accountNumber + ':' + apiKey).toString('base64')}`, `Accept: application/json`.
    - Parse JSON response as array. Take first element.
    - For each field (`colorFrontImage`, `colorBackImage`, `colorSideImage`): if non-empty, construct full URL as `'https://www.ssactivewear.com/' + relativePath` (replace `_fm` with `_fl` for large version).
    - Score each URL via `scoreUrl()`.
    - On HTTP error or catch, log warning and return `{}`.

    **sourceImages(styleId: string, colorName?: string): Promise<SourcedImages>**
    - Per D-01: fire all three fetchers with `Promise.allSettled([fetchOMGImages(styleId, colorName), fetchCSWImages(styleId), fetchSSCanadaImages(styleId)])`.
    - Collect candidates per view into `{ front: SourcedView[], back: SourcedView[], side: SourcedView[] }`.
    - For each settled result: if fulfilled, iterate entries and push to candidates. If rejected, log warning with `logger.warn()`.
    - Return `{ front: pickBest(candidates.front), back: pickBest(candidates.back), side: pickBest(candidates.side) }`.
    - Per D-05: no caching.

    **Imports needed:**
    ```typescript
    import * as cheerio from 'cheerio';
    import { downloadImage } from '../shopify/image-standardizer.js';
    import { scoreImageQuality } from '../shopify/image-scorer.js';
    import { createOneSourceClient, parseMediaContentFromXml } from './onesource-client.js';
    import { logger } from './logger.js';
    ```
