    Internal helper `callImagesEdit(client, inputBuffer, prompt, n)`:
    - Resize inputBuffer to 1024x1024 PNG using `sharp(inputBuffer).resize(1024, 1024, { fit: 'contain', background: { r: 255, g: 255, b: 255, alpha: 1 } }).png().toBuffer()`
    - Call `client.images.edit({ model: 'gpt-image-1', image: await toFile(resized, 'input.png', { type: 'image/png' }), prompt, n, size: '1024x1024' as const, quality: 'medium' as const })`

    - Map `response.data` to `Buffer.from(img.b64_json!, 'base64')`
    - Wrap in try/catch: if error is `OpenAI.BadRequestError` and message includes 'content_policy' or 'safety', log warning and return empty array. Otherwise re-throw.
    - Check `response.data.length` before mapping — handle partial results (some images may be null).

    Main function `generateGarmentView(frontBuffer, view, garmentType, colorName, costTracker, client?)`:
    - Per D-07: Check `costTracker.canAfford(CANDIDATES_PER_CALL * COST_PER_IMAGE)`. If false, log warning and return null.
    - Extract front image dominant hue via `extractDominantHue(frontBuffer)`.
    - Build prompt via `buildPrompt(garmentType, view, colorName)`.
    - Call `callImagesEdit(client, frontBuffer, prompt, CANDIDATES_PER_CALL)`.
    - Record cost: `costTracker.record(CANDIDATES_PER_CALL * COST_PER_IMAGE)`.
    - Score each candidate via `scoreImageQuality(candidateBuffer, garmentType)`.
    - For each candidate, compute hue drift via `extractDominantHue(candidateBuffer)` + `hueDrift()`.
    - If front is achromatic, skip hue check for all candidates.
    - Filter candidates: passes hue check (drift <= 15) OR front is achromatic. Among passing, pick highest score.
    - If NO candidates pass: check budget for retry. Build retry prompt via `buildRetryPrompt()`. Call again with n=3. Record cost. Score + filter again. Combine all 6 candidates.
    - If STILL no candidates pass after retry (per D-04): pick the best-scoring candidate from all 6 regardless of hue.
    - Return `GenerateViewResult` with the selected buffer, score, verdict, totalCost, callCount (1 or 2), usedRetry, hueDrift of selected.

    Function `enhanceFrontImage(frontBuffer, costTracker, garmentType?, client?)`:
    - Per D-05: Uses images.edit with CLEANUP_PROMPT and the real front image as input.
    - Check budget for 1 image cost.
    - Call `callImagesEdit(client, frontBuffer, CLEANUP_PROMPT, 1)`.
    - Record cost: `costTracker.record(1 * COST_PER_IMAGE)`.
    - Score the result via `scoreImageQuality()`.
    - Return `EnhanceFrontResult` with buffer, score, verdict, cost.
