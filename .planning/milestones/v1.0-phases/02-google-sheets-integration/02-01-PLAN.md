Create `src/sheets/reader.ts`:
- `readAllRows(sheets: sheets_v4.Sheets, spreadsheetId: string, sheetName?: string): Promise<{ headers: string[]; rows: SheetRow[] }>`
- Uses `spreadsheets.values.get` with range = sheetName (default from `GOOGLE_SHEET_NAME` env var or "Sheet1")
- Row 1 = headers, remaining rows = data
- Pads each row array to `headers.length` with empty strings to handle ragged rows (Pitfall 3 from research)
- Maps each padded row array to a `SheetRow` object using header-to-index mapping
- Throws descriptive error if sheet is empty or has only a header row

Create `tests/sheets/reader.test.ts`:

- Test: empty sheet (no values) -> throws "Sheet has no data"
- Test: header-only sheet (1 row) -> throws "Sheet has no data rows"
- Test: PartID is correctly mapped from the column position
