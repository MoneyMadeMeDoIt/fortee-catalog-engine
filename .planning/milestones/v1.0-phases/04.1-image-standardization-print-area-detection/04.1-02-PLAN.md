**Step 1 — Update processProductImages in src/shopify/image-standardizer.ts:**

Change signature to:
```typescript

  client: ShopifyClient,
  imageUrls: { front?: string; back?: string; side?: string },
  productName: string,
  colorName: string,
  categoryGroup: CategoryGroup,
): Promise<ImageProcessResult>
```

Import `CategoryGroup`, `PrintAreaCoords`, `ImageProcessResult` from `./types.js`.

Implementation changes:
- For `front` and `back` images: after downloading raw buffer, call `standardizeImage(raw, categoryGroup)` instead of the old `standardizeImage(raw)`. This returns `{ buffer, garmentPlacement }`.
- For `side` images: use simple `sharp(raw).resize(2000, 2000, { fit: 'contain', background: { r: 255, g: 255, b: 255, alpha: 1 } }).png().toBuffer()` — do NOT run garment detection on side images.
- After processing the front image, use `garmentPlacement` to call `derivePrintAreaCoords(garmentPlacement.left, garmentPlacement.top, garmentPlacement.width, garmentPlacement.height, categoryGroup)` to get the print area coords.
- Return `{ files, printAreaCoords }` where printAreaCoords is computed from the front image's garment placement, or null if front image processing failed.
