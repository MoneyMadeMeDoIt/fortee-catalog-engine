  <name>Task 1: Create unified extraction index and CLI script</name>
  <files>src/suppliers/index.ts, scripts/scrape.ts</files>
  <action>
1. Create `src/suppliers/index.ts`:
   - Import CanadaSportswearAdapter, SSCanadaAdapter, validateProduct, SupplierProduct, logger.
   - Export `type ExtractionResult = { supplier: string; products: SupplierProduct[]; validationErrors: Array<{ styleNumber: string; errors: string[] }>; summary: { total: number; valid: number; invalid: number } }`.
   - Export `async function extractFromSupplier(supplier: 'canada-sportswear' | 'ss-canada'): Promise<ExtractionResult>`:
     - Create the appropriate adapter.
     - Call fetchProducts().
     - Validate each product through validateProduct.
     - Collect valid products and validation errors separately.
     - Log summary: "Extracted N products from {supplier}: M valid, K invalid".
     - Return ExtractionResult.
   - Export `async function extractAll(): Promise<ExtractionResult[]>`:
     - Run extractFromSupplier for both suppliers (sequentially -- CSW first since it has no rate limits, then S&S).
     - Return array of results.

2. Create `scripts/scrape.ts`:
   - Import dotenv/config (first line, before other imports).
   - Import extractAll, extractFromSupplier from '../src/suppliers/index.js'.
   - Parse CLI args: `--supplier canada-sportswear` or `--supplier ss-canada` or no flag for both.
   - Also support `--style <id>` for single product extraction (calls adapter.fetchProduct).
   - Call the appropriate function.
   - For each result, print:
     - Header: "=== {supplier} ==="
     - Summary: "Total: N | Valid: M | Invalid: K"
     - For each valid product: one-line summary "{styleNumber}: {title} ({variants.length} variants, {images.length} images)"
     - For each validation error: "{styleNumber}: INVALID - {errors.join(', ')}"
   - Exit with code 1 if any products failed validation, 0 if all valid.
   - Wrap in try/catch: log error message, exit with code 1.

NOTE: The .js extension in the import path (`../src/suppliers/index.js`) is required for ESM resolution with nodenext. TypeScript resolves .js to .ts at compile time.
