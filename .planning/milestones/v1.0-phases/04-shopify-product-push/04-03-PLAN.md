   - Import `getCategoryGroup, buildVariants, buildHandle, SUPPORTED_CATEGORIES` from variants.ts

   **Rework `buildProductSetInput`** signature: `buildProductSetInput(rows: SheetRow[], files: FileSetInput[]): { input: ProductSetInput; identifier: { handle: string } } | null`
   - First, check category: call `getCategoryGroup(rows[0].baseCategory)`. If null, return null (unsupported category).
   - Build handle, variants (passing categoryGroup), template suffix
   - 3 productOptions: Color (position 1), Size (position 2), '# of Print Areas' (position 3, values: [{name: '1'}, {name: '2'}])

   - Template suffix from getTemplateSuffix (always 'quick-order')
   - Remove the isUpdate parameter -- always include files (staged upload resourceUrls)

   **Rework `pushProduct`** signature: `pushProduct(styleID: string): Promise<{ productGid: string; variantCount: number }>`
   - Step 1: Create Shopify client
   - Step 2: Read sheet rows, filter by styleID
   - Step 3: Check category support via getCategoryGroup. If null, throw with descriptive message listing supported categories.
   - Step 4: Look up existing metaobject GIDs via `getExistingPrintAreaGids(client)` -- do this once (could be cached but fine to call each push for now)
   - Step 5: Process images via `processProductImages(client, { front: rows[0].FrontImage, back: rows[0].BackImage, side: rows[0].DirectSideImage }, rows[0].productName, rows[0].colorName)`
   - Step 6: Build productSet input via `buildProductSetInput(rows, files)`
   - Step 7: Call PRODUCT_SET mutation with `{ input, synchronous: true }`
   - Step 8: Handle userErrors (throw with messages)
   - Step 9: Set product-level metafields via METAFIELDS_SET:
     - Print Areas: `{ ownerId: productGid, namespace: 'custom', key: 'print_areas', type: 'list.metaobject_reference', value: JSON.stringify(metaobjectGids) }`
     - Minimum Order Quantity: `{ ownerId: productGid, namespace: 'custom', key: 'minimum_order_quantity', type: 'number_integer', value: '0' }`
   - Step 10: Log success, return { productGid, variantCount }
   - Remove metaobjectCount from return (we don't create metaobjects anymore)
