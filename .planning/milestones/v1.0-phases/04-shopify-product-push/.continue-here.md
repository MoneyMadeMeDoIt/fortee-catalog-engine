## Image Standardization & Print Area Detection

**Problem:** Two related issues with the current approach:

1. **Garment proportion mismatch** — `standardizeImage()` uses `sharp.resize(2000x2000, fit: contain)` which just scales and centers. Different supplier images have different garment-to-canvas ratios, so the garment doesn't match the reference proportion. The print area box ends up misaligned.

2. **Fixed print area coordinates don't work** — The hardcoded coordinates (per category: tops vs hoodies) don't account for garment shape variations (e.g. raglan sleeves, women's cuts). The blue dotted box ends up way too large or mispositioned.

**Solution direction:** Automated garment detection via image processing (not manual per-product):
- Detect garment edges / remove background
- Scale and position the garment to match the reference garment-to-canvas ratio
- Derive print area coordinates from the detected garment boundaries
- This solves both problems in one pass — consistent images AND accurate print areas

**Approach:** Push products one by one, refine the flow each time until it's reliable. No batch processing yet.
