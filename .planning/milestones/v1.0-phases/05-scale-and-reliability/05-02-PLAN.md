<task type="auto" tdd="true">
  <name>Task 1: Create batch push orchestrator with error isolation and progress</name>
  <files>src/shopify/batch-push.ts, tests/shopify/batch-push.test.ts</files>
  <behavior>
    - batchPush iterates all styleIDs sequentially and returns BatchResult[] with correct statuses
    - When pushProductFromRows succeeds: result has status 'success' with productGid and variantCount
    - When pushProductFromRows throws "Unsupported category": result has status 'skipped' with skipReason
    - When pushProductFromRows throws other error: result has status 'failed' with error message
    - Failure on one product does not prevent subsequent products from being processed
    - THROTTLED errors trigger retry with backoff (up to 3 attempts)
    - printProgress is called after each product with done count, total, and current styleID
  </behavior>
  <action>
    1. Install p-queue: `npm install p-queue`

    2. Create `src/shopify/batch-push.ts`:
       - Export `BatchResult` interface: { styleID, status: 'success'|'skipped'|'failed', productGid?, variantCount?, skipReason?, error? }
       - Export `BatchOptions` interface: { dryRun?: boolean, limit?: number, styleIDs?: string[], onProgress?: (done: number, total: number, current: string) => void }
       - Export `batchPush(options: BatchOptions): Promise<BatchResult[]>`
       - batchPush flow:
         a. Read sheet once: `createSheetsClient()` + `readAllRows()`
         b. Group rows by styleID into `Map<string, SheetRow[]>`
         c. Filter to options.styleIDs if provided, otherwise use all
         d. Apply options.limit if provided (take first N)
         e. If options.dryRun: call `buildDryRunPreview(allRows)`, print table, return early with results mapped to BatchResult format
         f. For live mode: iterate styleIDs with PQueue(concurrency: 1)
         g. Each product: call `pushWithRetry(styleID, rows)` which wraps `pushProductFromRows(rows)` in try/catch with THROTTLED retry (3 attempts, linear backoff 2s/4s/6s)
         h. After each product: call `options.onProgress?.(done, total, styleID)` and increment done counter
         i. Return all BatchResult[]

       - Internal `pushWithRetry(styleID: string, rows: SheetRow[], maxRetries = 3): Promise<BatchResult>`:
         - Loop up to maxRetries
         - Call pushProductFromRows(rows)
         - On success: return { styleID, status: 'success', productGid, variantCount }
         - On error with "throttl" (case-insensitive): wait attempt * 2000ms, retry
         - On error with "Unsupported category": return { styleID, status: 'skipped', skipReason: message }
         - On other error: return { styleID, status: 'failed', error: message }

       - Export `printProgress(done: number, total: number, current: string): void`:
         - `process.stdout.write(\r[done/total] pct% - current)` padded to 80 chars
         - Newline when done === total

       - Export `printSummary(results: BatchResult[]): void`:
         - Count success/failed/skipped
         - Print summary line: "Success: N | Failed: N | Skipped: N"
         - List failed products with their error messages
         - List skipped products with their skip reasons

    3. Create `tests/shopify/batch-push.test.ts`:
       - Mock `pushProductFromRows` from `../src/shopify/product-push.js`
       - Mock `createSheetsClient` and `readAllRows` to return fixture rows
       - Mock `buildDryRunPreview` from `../src/shopify/dry-run.js`
       - Test: 3 products all succeed => 3 success results
       - Test: middle product throws generic error => first success, second failed, third success (error isolation)
       - Test: product throws "Unsupported category" => status is 'skipped' not 'failed'
       - Test: product throws "THROTTLED" then succeeds on retry => final status is success
       - Test: dryRun option calls buildDryRunPreview and does NOT call pushProductFromRows
       - Test: limit option processes only first N products
  </action>
  <verify>
    <automated>npx vitest run tests/shopify/batch-push.test.ts</automated>
  </verify>
  <done>batchPush processes products sequentially with error isolation. THROTTLED retry works. Dry-run mode uses pure functions only. All batch tests pass.</done>
</task>

    - showHelp function with usage docs:

      Usage:
        npx tsx scripts/push-batch.ts                    Push all supported products

        npx tsx scripts/push-batch.ts --limit 5          Push first 5 products only
        npx tsx scripts/push-batch.ts ST100 ST200        Push specific styleIDs
        npx tsx scripts/push-batch.ts --dry-run ST100    Dry-run specific styleIDs

      Environment variables required:
