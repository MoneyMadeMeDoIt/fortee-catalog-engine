   Note: `getExistingPrintAreaGids` is already imported from metaobjects.js -- add the new functions to that existing import.

   b. Add step 13b after the existing step 13 metafieldsSet block (after line ~321, before the "// 14. Query product media" comment):

   ```typescript
   // 13b. Upsert size guide metaobject and link to product
   const specSpreadsheetId = process.env.SPEC_SHEET_GOOGLE_SPREADSHEET_ID;
   if (specSpreadsheetId) {
     try {
       const specMap = await readSpecSheetStructured(sheets, specSpreadsheetId);
       const productSpecs = specMap.get(rows[0].productId);
       if (productSpecs && productSpecs.length > 0) {
         const sizeGuideGid = await upsertSizeGuideMetaobject(
           client,
           rows[0].productId,
           rows[0].productName,
           productSpecs,
         );
         await linkSizeGuideToProduct(client, productGid, sizeGuideGid);
         logger.info(`Linked size guide to product: ${sizeGuideGid}`);
       } else {
         logger.warn(`No spec data for productId "${rows[0].productId}" -- skipping size guide`);
       }
     } catch (err) {
       logger.warn(`Size guide creation failed (non-fatal): ${err instanceof Error ? err.message : err}`);
     }
   }
   ```

   Key points:
   - Wrap in try/catch -- size guide failure should NOT fail the entire product push (same pattern as print_area_media errors which use logger.warn)
   - `sheets` variable already exists from line 92 (`createSheetsClient()`)
   - `rows[0].productId` is the styleName/productId used in spec sheet matching
   - If `SPEC_SHEET_GOOGLE_SPREADSHEET_ID` env var is not set, skip silently (no warning needed -- not all users have spec sheets)
