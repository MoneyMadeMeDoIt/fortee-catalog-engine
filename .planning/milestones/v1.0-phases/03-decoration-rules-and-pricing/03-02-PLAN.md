Create `src/sheets/enrich-decoration.ts`:
- Import createSheetsClient from client.ts, readAllRows from reader.ts, writeUpdates from writer.ts, columnToLetter from column-map.ts
- Import resolveCategory, getDecorationRulesForCategory, calculateSellPrice from decoration/index.ts
- Define interface `DecorationEnrichOptions { dryRun?: boolean; discountPercent?: number }`
- Export `async function enrichDecoration(options: DecorationEnrichOptions = {}): Promise<EnrichmentReport>`
- Pipeline:
  1. Create sheets client, read spreadsheetId and sheetName from env
  2. readAllRows to get all rows
  3. For each row:
     a. resolveCategory(row.baseCategory) -- skip if null (report as skippedNoMatch)
     b. getDecorationRulesForCategory(category) to get placements
     c. Determine embroideryAvailable = placements.some(p => p.method === 'Embroidery') ? 'Yes' : 'No'
     d. Determine dtfAvailable = placements.some(p => p.method === 'Print') ? 'Yes' : 'No'
     e. Format decorationPlacements as semicolon-separated list: "Print: Left Chest, Full Front; Embroidery: Left Chest" (group by method, list placement names)
     f. Parse costPrice as number. If valid and > 0, call calculateSellPrice with printAreas = count of Print placements (use 1 as default for pricing -- the most common case), embroideryAreas = 0 (embroidery is order-specific per research), stitchCount = 0, discountPercent = options.discountPercent ?? 0.45
     g. Build EnrichmentUpdate objects for: embroideryAvailable, dtfAvailable, decorationPlacements, sellPrice -- using fill-gaps-only semantics (only write if cell is currently empty, matching the pattern from merge.ts buildUpdates)
  4. Batch write all updates via writeUpdates
  5. Return EnrichmentReport

Create `tests/decoration/enrich-decoration.test.ts`:
- Test the decoration data formatting (semicolon-separated placements)
- Test that enrichDecoration correctly resolves categories and builds updates
- Test fill-gaps-only: cells with existing values are not overwritten
- Test that unknown categories are skipped and counted in skippedNoMatch
- Mock the sheets client (no live API calls in tests)
