- Export `getDecorationRulesForCategory(category: GarmentCategory): DecorationPlacement[]` that filters ALL_PLACEMENTS to those whose body category is in CATEGORY_TO_BODY_LOCATIONS[category]

  <name>Task 2: Pricing calculator with tests and barrel export</name>
  <files>src/decoration/pricing.ts, src/decoration/index.ts, tests/decoration/pricing.test.ts</files>
  <behavior>
    - calculateSellPrice({garmentCost: 7.80, printAreas: 1, embroideryAreas: 0, stitchCount: 0, discountPercent: 0.45}).sellPrice === 14.08
    - calculateSellPrice with 0 print areas and 0 embroidery areas returns msrp * (1 - discount) as sell price
    - calculateSellPrice with 2 print areas: printCost = 10 + 6 = 16
    - calculateSellPrice with 3 print areas: printCost = 10 + 6 + 6 = 22
    - calculateSellPrice with 1 embroidery area, 5000 stitches: embroideryCost = 20
    - calculateSellPrice with 1 embroidery area, 10000 stitches: embroideryCost = 10 + 0.80 * 10 = 18
    - calculateSellPrice with 1 embroidery area, 21120 stitches (stitch estimator example): embroideryCost = 10 + 0.80 * 21.12 = 26.896
    - grossMargin is calculated as (sellPrice - garmentCost) / sellPrice
    - sellPrice is rounded to 2 decimal places
    - Zod schema rejects negative garmentCost, negative areas, discountPercent > 1
  </behavior>
  <action>
Create `src/decoration/pricing.ts`:
- Import PricingInput, PricingResult from types.ts
- Implement `calculateSellPrice(input: PricingInput): PricingResult` as a pure function:
  - msrp = garmentCost * 2
  - printCost: first area $10, each additional $6 (0 areas = $0)
  - embroideryCost: per area, if stitchCount <= 8000 then $20/area, else ($10 + $0.80 * stitchCount/1000) per area
  - totalDecorationCost = printCost + embroideryCost
  - priceBeforeDiscount = msrp + totalDecorationCost
  - discount = priceBeforeDiscount * discountPercent
  - sellPrice = round to 2 decimals (priceBeforeDiscount - discount)
  - grossMargin = round to 4 decimals ((sellPrice - garmentCost) / sellPrice)
- Also export `estimateStitchCount(lengthInches, widthInches, coveragePercent = 0.40): number` for optional use

Create `src/decoration/index.ts`:
- Re-export getDecorationRulesForCategory from rules.ts
- Re-export calculateSellPrice, estimateStitchCount from pricing.ts
- Re-export resolveCategory from category-map.ts
- Re-export all types from types.ts

Write tests FIRST (RED), then implement (GREEN):
- `tests/decoration/pricing.test.ts`: Test reference case ($7.80, 1 print, 45% = $14.08), multiple print areas, embroidery under/over 8000 stitches, zero decorations, gross margin calculation, rounding behavior

Run full test suite to confirm no regressions.
